poche-resend-webmail

OSS self-hosted Resend webmail over poche. Go BFF + React CDN UI. MIT.

GitHub Powered by poche grange (storage engine)

Features

Multi-tenant mailboxes
Per-address auth, storage caps, aliases, catch-all domains, forgot-password.
Resend + SMTP inbound
Webhook ingestion or built-in SMTP receiver. Scheduled sync caches before retention expires.
Gmail-style threading
Thread collapsing, full conversation view, multi-account switcher.
Tag management
Auto-tag spam/DMARC, tag-similar modal, tag counts, hide tagged from inbox.
Rich compose
WYSIWYG HTML, Markdown split preview, attachments, minimizable modal.
Self-hosted, no dependencies
Single Go binary, embedded UI, poche/grange storage. MIT licensed.
